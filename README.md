# Eluma — Платформа разовых смен и бытовых поручений в Самаре (v16 Quiet Fintech Architecture)

Адаптивное финтех веб-приложение (**Mobile `< 768px` + Tablet `768–1023px` + Desktop Split-View `>= 1024px`**) для поиска разовых смен от локального бизнеса (B2B) и бытовых поручений от жителей Самары (P2P) с гарантией безопасных расчётов `Eluma Safe`, многоуровневой сертификацией допуска Ozon-style, подтверждением геопозиции по GPS в Самаре, чистой картой Esri ArcGIS без водяных знаков и фотофиксацией ДО/ПОСЛЕ.

Интерфейс выполнен по стандартам продуктового финтех-дизайна (Stripe, Linear, Т-Банк) в спокойной палитре **Quiet Fintech** со **100% векторной SVG-системой (ZERO EMOJI & ZERO PSEUDO-SYMBOLS)**.

---

## 1. Чистая модульная архитектура v16

В кодовой базе ликвидирован устаревший монолит: приложение разбито на независимые модульные страницы и контроллеры, связанные реактивным ядром в пространстве имён `window.Eluma` (с сохранением обратной совместимости через `window.Olksi`):

```
eluma-root/
├── index.html          # Авторизация Eluma ID: бесшовный вход и регистрация по роли
├── worker.html         # Выделенный кабинет исполнителя (лента, сплит-карта Самары, смены)
├── employer.html       # Выделенный кабинет заказчика (изоляция заказов по ownerId)
├── styles.css          # Единая дизайн-система Quiet Fintech (сбалансированные блоки, адаптив 360px+)
├── start.bat           # 1-клик запуск через file:// протокол (без CORS-ограничений)
├── package.json        # Стандартные npm-скрипты тестирования
├── audit_all_views.js  # Сквозной аудит всех вкладок, модалок и адаптивности (360px..1920px)
├── core/
│   ├── store.js        # Реактивное хранилище eluma_db_v16, STATUS_MAP, BroadcastChannel
│   ├── ui.js           # 100% Inline SVG, модалки, тосты, безопасный escapeHtml(0)
│   ├── courses.js      # 7 интерактивных курсов допуска (Ozon-style, 3 урока, 5 вопросов)
│   └── seed.js         # База Самары: 18 заказов с уникальными координатами, пользователи, отзывы
├── worker/
│   └── app.js          # Контроллер исполнителя (лента, смены, выплаты СБП, карта Esri, чаты)
├── employer/
│   └── app.js          # Контроллер заказчика (создание смен, эскроу, публичная карточка, приёмка)
└── dev/
    └── toolkit.js      # Dev Bar v16: переключение ролей в 1 клик, модалка дебага
```

## 2. Ключевые возможности кабинетов

### Кабинет исполнителя (`worker.html`)
- **Лента смен Самары**: раздельный вид со списком карточек и интерактивной картой Самары на базе Esri World Street Map (0 API-ключей, 0 водяных знаков, 0 сторонних флагов). Фильтрация по 6 категориям (`ПВЗ`, `Помощь на участке`, `Склад/Ритейл`, `Физическая помощь`, `Мелкий ремонт`, `Курьер`).
- **Гейткипер допуска (Ozon-style)**: при попытке взять смену без действующего сертификата открывается интерактивный плеер курса с авто-возвратом к записи после успешной сдачи.
- **Мои записи**: переключение между активными и архивными сменами со статусами выполнения.
- **Выплаты и доход**: баланс кошелька, моментальный вывод по СБП (15 мин), история начислений и официальные чеки ФНС РФ (НПД).
- **Профиль и сертификация**: чек-лист готовности, 7 курсов допуска со сроком действия 12 месяцев и разбором ошибок.

### Кабинет заказчика (`employer.html`)
- **Изоляция заказов по `ownerId` (D4)**: заказчик видит исключительно свои созданные смены (например, 10 заказов юр. лица 101), а не общую базу маркетплейса.
- **Мастер публикации смен**: прямое назначение фиксированной цены, быстрые пресеты, выбор района Самары, времени и требований. Резервирование средств на эскроу-счёте `Eluma Safe`.
- **Публичная карточка исполнителя**: имя с инициалом, верификация НПД и телефона, количество выполненных смен, рейтинг, бейджи пройденных курсов. В соответствии с 289-ФЗ телефон и персональные данные надёжно скрыты.
- **Контроль выполнения**: слоты фотофиксации ДО/ПОСЛЕ, GPS-штамп прибытия, приёмка работы в 1 клик или возврат на доработку с мотивированными замечаниями.

## 3. Dev Bar и тестирование

Аккуратная плавающая панель разработчика расположена в правом нижнем углу экрана (`z-index: 9999`):
1. **Быстрое переключение роли в 1 клик**: мгновенный переход между активным исполнителем (Алексей К.) и заказчиком (СтройСамара).
2. **Кнопка DEV**: открытие расширенного Dev Toolkit со вкладками управления эскроу, сброса базы и симуляции смены статусов.

## 4. Автоматические тесты и верификация

Запуск полного тестового контура в одну команду:
```bash
npm test
```

Или по отдельным направлениям:
- `npm run test:static` (`node v14_static_audit.js`): **89 проверок PASS** (целостность файлов, отсутствие запрещённых символов, баланс тегов и скобок CSS, Quiet Fintech токены).
- `npm run test:browser` (`node v14_browser_test.js`): **23 проверки PASS** (сквозные пользовательские сценарии в headless Chromium, 0 ошибок консоли).
- `npm run test:map` (`node verify_map_fix.js`): **8 проверок PASS** (проверка Esri ArcGIS, отсутствие водяных знаков и флагов, 18 уникальных гео-координат).
- `node audit_all_views.js`: **100% PASS** на всех разрешениях экрана (360px, 480px, 768px, 1024px, 1440px, 1920px) без переполнения `overflow-x`.
